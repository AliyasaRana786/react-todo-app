# React Todo App

A beginner-friendly Todo List built with React and Vite.

## Run locally

1. Open this folder in VS Code.
2. Open Terminal → New Terminal.
3. Run:

   ```bash
   npm install
   npm run dev
   ```

4. Open the local URL shown in the terminal (usually http://localhost:5173).

## Features

- Add tasks
- Mark tasks as completed
- Delete tasks
- Responsive layout

## Production build

```bash
npm run build
```
